# 声波配网技术文档

> 本文档详细介绍了小智AI设备的声波配网功能，包括技术原理、使用方法、调试工具和开发指南。

## 功能概述

### 什么是声波配网
声波配网是一种通过音频信号传输WiFi凭据的技术，用户可以通过播放特定的声波信号，将WiFi的SSID和密码传输给设备，实现无接触的WiFi配置。

### 主要特点
- **无接触配网**：无需手动输入WiFi信息
- **科幻体验**：通过声波传输数据，具有科技感
- **兼容性好**：支持多种设备和平台
- **实时反馈**：可实时监控配网状态

## 技术原理

### AFSK调制解调
声波配网使用AFSK（Audio Frequency-Shift Keying）技术：

- **MARK频率**：1.8kHz，表示数字"1"
- **SPACE频率**：1.5kHz，表示数字"0"
- **比特率**：100 bps
- **采样率**：16kHz

### 数据传输协议
```
[起始帧] [数据] [校验和] [结束帧]
```

- **起始帧**：0x01 0x02
- **结束帧**：0x03 0x04
- **校验和**：简单的累加校验
- **数据格式**：SSID\n密码

### 信号处理流程
1. **音频采集**：设备麦克风采集音频信号
2. **频率检测**：使用Goertzel算法检测特定频率
3. **比特解码**：将频率转换为数字比特
4. **数据重组**：重组为完整的WiFi凭据
5. **连接验证**：尝试连接WiFi网络

## 硬件要求

### 设备端要求
- **麦克风**：支持1.5kHz-1.8kHz频率范围
- **音频编解码器**：支持16kHz采样率
- **处理器**：能够实时处理音频数据

### 播放端要求
- **扬声器**：支持1.5kHz-1.8kHz频率播放
- **音频输出**：支持16kHz采样率
- **音量控制**：能够调节到合适音量

## 使用方法

### 1. 设备端配网流程

#### 进入配网模式
1. 设备启动后自动进入配网模式
2. 创建WiFi热点（如：Xiaozhi-D3DD）
3. 等待声波信号

#### 配网过程
1. 设备监听音频输入
2. 检测到起始帧后开始接收数据
3. 解码WiFi凭据
4. 尝试连接WiFi网络
5. 连接成功后重启设备

### 2. 用户端操作流程

#### 使用HTML工具
1. 打开 `docs/sonic_wifi_config.html`
2. 输入WiFi的SSID和密码
3. 点击"生成并播放声波"
4. 等待配网完成

#### 使用小程序/APP
1. 进入配网页面
2. 输入WiFi信息
3. 播放声波信号
4. 等待配网结果

## 故障排除

### 常见问题

#### 1. 配网失败
**可能原因**：
- 音量太小或太大
- 环境噪音干扰
- 设备距离太远
- 音频设备不支持

**解决方案**：
- 调整音量到合适大小
- 在安静环境中测试
- 设备靠近播放源
- 检查音频设备兼容性

#### 2. 解码错误
**可能原因**：
- 信号质量差
- 频率偏移
- 采样率不匹配

**解决方案**：
- 使用调试工具检查信号质量
- 调整频率参数
- 确认采样率设置

#### 3. WiFi连接失败
**可能原因**：
- WiFi密码错误
- 网络不可用
- 设备不支持该网络

**解决方案**：
- 检查WiFi密码
- 确认网络可用性
- 检查设备网络支持

### 调试步骤

#### 1. 信号质量检查
1. 使用Python调试工具
2. 观察频域图中的1.5kHz和1.8kHz峰值

#### 3. 网络连接检查

2. 确认WiFi连接状态
3. 检查IP地址分配
